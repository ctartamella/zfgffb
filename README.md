# Team ZFG Active Pedal Design

This repository contains an amalgamation of DIY pedal designs from around the Internet to create a single optimal pedal design with thorough documentation and the most up to date feature set.

This includes:

* Gilphilbert V2 board
* XT30 connectors with simpler wiring
* 350W and 600W PSU options
* Multiple pedal options
* Complete BOM for all scenarios
* Easy to follow instructions

## Project Offerings

Included in this project's releases are a few key artifacts to help you build

* A full 3MF file for 3D printing including print settings.
* A full BOM covering various power supply and pedal options

Also included is a Wiki with full instructions to build this pedal for yourself.
